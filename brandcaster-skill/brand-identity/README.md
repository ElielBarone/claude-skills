# Brand workspace config

Copy this folder (e.g. to `brand/`) and edit `config.json` for your company.

**config.json** is the only config file. You can change `brandName`, `palette`, typography, spacing, rules, logo paths, and `templateFolder`. Folders can be renamed; update paths in config to match.

**icons/** – add PNG or SVG files here to use as icons in your presentations.
